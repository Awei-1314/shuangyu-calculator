# 双鱼部落收益计算器 - 网页版（带后端卡密系统）

## 功能说明

- 姓名登录：输入姓名即可进入查看（只读模式）
- 卡密激活：输入卡密后解锁全部编辑功能
- 设备绑定：卡密激活后自动绑定当前电脑，其他电脑无法使用
- 管理员系统：管理员登录后可生成/管理卡密
- 卡密类型：1小时体验卡、周卡（7天）、月卡（30天）、永久卡

## 安装运行

### 1. 安装 Node.js

确保电脑已安装 Node.js（建议 v16 或更高版本）
下载地址：https://nodejs.org/

### 2. 安装依赖

在项目目录下打开命令行，运行：

```bash
npm install
```

### 3. 启动服务

```bash
npm start
```

启动成功后会显示：
```
双鱼部落收益计算器已启动：http://localhost:3000
```

### 4. 访问使用

在浏览器打开：http://localhost:3000

## 局域网访问（其他电脑也能用）

如果想让同一局域网内的其他电脑也能访问：

1. 查看本机IP地址（Windows运行 `ipconfig`，找 IPv4 地址）
2. 其他电脑浏览器打开：`http://你的IP:3000`

例如你的IP是 `192.168.1.100`，其他电脑就打开 `http://192.168.1.100:3000`

## 卡密系统说明

### 卡密激活流程

1. 用户输入姓名进入（只读模式）
2. 点击右上角"激活卡密"
3. 输入卡密，激活成功后自动绑定当前电脑
4. 同一卡密在其他电脑使用会提示"卡密已被其他电脑激活"

### 管理员生成卡密

1. 登录界面点击"管理员登录"
2. 输入管理员账号密码
3. 点击右上角"卡密管理"
4. 选择卡密类型和数量，点击"生成卡密"
5. 生成的卡密可以复制发给用户

### 卡密数据存储

卡密数据保存在 `data/cards.json` 文件中，重启服务数据不会丢失。

## 常见问题

### Q: 启动提示端口被占用？
A: 修改 `server.js` 中的 `PORT` 变量，换成其他端口（如 3001）

### Q: 其他电脑访问不了？
A: 检查Windows防火墙是否放行Node.js，或者关闭防火墙测试

### Q: 卡密数据怎么备份？
A: 复制 `data/cards.json` 文件即可

### Q: 怎么修改管理员密码？
A: 修改 `server.js` 中的 `ADMIN` 对象
